# mh-content-planner

Tablero de Salida — planner de contenido para Mastery Haus y Sofia Contreras.

Ver [CLAUDE.md](CLAUDE.md) para el contexto del proyecto, [DECISIONS.md](DECISIONS.md) para las decisiones de arquitectura, y [TODO.md](TODO.md) para el plan por fases y el estado actual.

## Desarrollo local

```bash
npm install
npm run dev
```

Necesita un archivo `.env.local` (ver `.env.local.example`) con las credenciales de Supabase y, a partir de la Fase 5, las de la app de Meta.
